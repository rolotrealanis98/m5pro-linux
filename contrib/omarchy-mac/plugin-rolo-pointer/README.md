# plugin-rolo-pointer

Omarchy shell panel that writes `~/.config/hypr/pointer-tuning.lua` for the Apple trackpad (acceleration curve, scroll, tap and drag).

- Scope: `t6050`. Status: installed. Upstream: Omarchy itself, as an optional plugin.
- Install: `sudo contrib/omarchy-mac/install-item.sh --user NAME plugin-rolo-pointer`. Add `rolo.pointer` to the bar layout in `shell.json`.
- Undo: `sudo contrib/omarchy-mac/install-item.sh --remove plugin-rolo-pointer` (originals come back from `*.before-omarchy-mac`).
- Files are captured from the MacBook on 2026-11-17; the row in `../INVENTORY.md` is the record.
