# plugin-rolo-tray

Omarchy shell tray (status notifier) widget.

- Scope: `generic`. Status: installed. Upstream: Omarchy itself (the bar has no tray widget).
- Install: `sudo contrib/omarchy-mac/install-item.sh --user NAME plugin-rolo-tray`. Add `rolo.tray` to the bar layout in `shell.json`.
- Undo: `sudo contrib/omarchy-mac/install-item.sh --remove plugin-rolo-tray` (originals come back from `*.before-omarchy-mac`).
- Files are captured from the MacBook on 2026-11-17; the row in `../INVENTORY.md` is the record.
