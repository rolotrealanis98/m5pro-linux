# omarchy-lite-fallback

The earlier Waybar and Mako desktop (omarchy-lite), selected with `m5pro-desktop lite`. Kept as a rescue desktop; `hypridle.conf` and `hyprlock.conf` here are its leftovers.

- Scope: `j716s`. Status: experimental. Upstream: none.
- Install: `sudo contrib/omarchy-mac/install-item.sh --user NAME omarchy-lite-fallback`. Needs waybar, mako, hypridle, hyprlock.
- Undo: `sudo contrib/omarchy-mac/install-item.sh --remove omarchy-lite-fallback` (originals come back from `*.before-omarchy-mac`).
- Files are captured from the MacBook on 2026-11-17; the row in `../INVENTORY.md` is the record.
